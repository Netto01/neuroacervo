# Imagens dos Cards de Recursos Interativos

Esta pasta armazena as imagens ilustradas de capa para os cards da seção **Recursos Interativos** (`/recursos-interativos`).

## Nomes e Arquivos Esperados

| Recurso | Nome do Arquivo Recomendado | Formatos Aceitos |
| :--- | :--- | :--- |
| **Histórias Clínicas & Regulação** | `historias-clinicas.webp` | `.webp`, `.jpg`, `.jpeg`, `.png` |
| **Baralho de Funções Executivas** | `baralho-funcoes-executivas.webp` | `.webp`, `.jpg`, `.jpeg`, `.png` |
| **Atividades de Atenção** | `atividades-atencao.webp` | `.webp`, `.jpg`, `.jpeg`, `.png` |
| **Treino de Percepção** | `treino-percepcao.webp` | `.webp`, `.jpg`, `.jpeg`, `.png` |

## Diretrizes de Imagem

- **Dimensões recomendadas:** `800 × 500 px` ou `600 × 400 px` (proporção aproximada de `16:10` ou `3:2`).
- **Resolução & Peso:** Formato `.webp` otimizado abaixo de `200 KB` para carregamento instantâneo.
- **Área Útil:** Mantenha os elementos visuais principais centralizados com margem de segurança nas bordas, pois o card adapta a imagem de forma responsiva (`object-fit: cover`).
- **Fallback Automático:** Caso alguma imagem ainda não tenha sido adicionada nesta pasta, o card exibe automaticamente o ícone original sem quebrar o layout.
